今日 AI 行业热点｜2026-09-15

2026 年 9 月 15 日

今日趋势点评

今天的 AI 行业热点集中在“可执行智能体”和“基础设施约束”两端：OpenAI、Google 和豆包都在把模型推向真实工具、语音和手机系统，DeepSeek 与 Qwen 则继续用长上下文、低成本和多模态能力争夺开发者入口。与此同时，Anthropic 的威胁报告、欧盟 AI 法案透明度要求和 Cornelis 的网络融资提醒行业，模型能力越强，企业真正要补齐的反而是权限边界、审计、算力利用率和合规工程。

国外新闻

  1. OpenAI Agents API 进入公开测试国外

    OpenAI 发布 Agents API public beta，将 Codex 背后的长时运行 harness、上下文压缩、工具搜索和并行 subagent 能力开放给开发者。

    来源：OpenAI 官方博客

    这不是单个模型升级，而是把“智能体运行时”产品化。开发团队可以把更多精力放在工具权限、业务环境和结果验收上，减少自研调度、上下文管理和沙箱基础设施的重复投入。

  2. OpenAI 将 GPT-Live-1 开放给 API 开发者国外

    OpenAI 推出 GPT-Live-1 API，支持全双工语音、打断处理、电话场景和后端模型/工具委派，定价为前端语音层每分钟 0.05 美元。

    来源：OpenAI 官方博客

    语音 agent 的核心瓶颈正在从“能否说话”转向“能否在自然对话中完成任务”。全双工能力和后端委派降低了传统 ASR-LLM-TTS 串联架构的复杂度，也让客服、预约、学习陪练等高频场景更接近生产级体验。

  3. Google 发布 Gemini 3.8 Flash 与 Cyber 版本国外

    Google 发布 Gemini 3.8 Flash，并面向可信防御方开放 Gemini 3.8 Flash Cyber，强调长程编码、智能体任务、漏洞发现和自动修复能力。

    来源：Google 官方博客

    Google 将通用低成本模型与受控安全模型分层发布，说明前沿能力正在按风险场景切片交付。对企业而言，这类模型的价值不只是跑分，而是能否在可审计边界内处理长流程代码和安全修复任务。

  4. Anthropic 披露 2026 年 9 月 AI 滥用威胁报告国外

    Anthropic 报告称，过去八个月已识别并中断多类 Claude 滥用案例，覆盖网络行动、影响力行动、监控、诈骗、生物滥用、常规武器和非法蒸馏。

    来源：Anthropic 威胁情报报告

    报告的关键信号是 AI 从问答辅助进入执行和编排环节，攻击者可以更低成本地完成侦察、工具修改、数据整理和规避检测。企业部署 agent 时，需要把最小权限、操作审计和异常阻断当作基础能力。

  5. Cornelis 获 2.05 亿美元融资并推出 Active Compute Fabric国外

    Cornelis Networks 发布面向 AI/HPC 的 Active Compute Fabric，并宣布获得 2.05 亿美元融资，Qualcomm 将在 AI Infra Summit 与其共同讨论 rack-scale AI 网络。

    来源：Cornelis 官方公告

    AI 基础设施竞争已经从 GPU 延伸到网络结构。Cornelis 将可编程计算放入网络 fabric，目标是降低通信等待和同步成本，这直接影响大规模训练、推理集群的有效利用率和投资回报。

  6. OpenAI 被曝以超 3 亿美元收购 Glass Imaging国外

    CTech 援引《华尔街日报》报道称，OpenAI 已收购智能手机相机 AI 技术公司 Glass Imaging，交易估值超过 3 亿美元，但双方未公开确认。

    来源：CTech 报道、Glass Imaging 官网

    该消息仍属于媒体报道口径，但方向值得关注：OpenAI 正把多模态能力向设备输入层延伸。若计算摄影团队进入其硬件体系，未来 AI 设备的竞争点可能不只在模型，还在传感器、边缘处理和真实世界上下文采集。

国内新闻

  1. 豆包手机助手消费者版本正式发布国内

    豆包手机助手官网显示，消费者版本已发布，将搭载在努比亚 NaviX Ultra 上，提供 AI 键、语音唤醒、识屏问答、操作手机 Beta、系统工具调用和本地数据检索等能力。

    来源：豆包手机助手官网

    这是国内大模型厂商把 agent 深度嵌入手机系统的一次关键落地。真正的商业变量在于第三方应用接入、敏感操作确认和本地隐私边界能否被稳定治理，否则“能操作手机”很难转化为可规模化的用户信任。

  2. DeepSeek V4.1 Flash 上线并调整 API 路由与价格国内

    DeepSeek 发布 V4.1 Flash，称其采用 552B 参数 MoE 与 Causal-Encoder-Decoder 结构，支持原生多模态视觉理解，并在 API 中以 `deepseek-flash` 调用。

    来源：DeepSeek 官方动态、DeepSeek API 价格文档

    DeepSeek 的重点是通过更低激活参数和更小 KV Cache 降低长上下文与 agent 场景成本。价格文档继续保留 V4 Pro API，也体现出模型升级中兼容性和计费确定性对开发者的重要性。

  3. 智谱披露近 393 亿港元融资方案国内

    智谱在港交所公告中披露，拟配售最多 2196.5 万股新 H 股，并发行人民币 201.4 亿元零息可换股债券，合计募资规模约 393 亿港元。

    来源：港交所公告

    这笔融资的用途直接指向下一代 GLM、完全自训练体系、训练推理算力和商业化扩张。它说明国内大模型公司仍处于高投入阶段，长期竞争不只看模型效果，也看融资、算力采购和推理效率的持续匹配。

  4. 阿里云百炼更新 Qwen3.8-2.4T-A95B 模型信息国内

    阿里云百炼文档显示，Qwen3.8-2.4T-A95B 为通义千问最新旗舰系列开源版本，采用 2.4 万亿参数稀疏 MoE、约 950 亿激活参数，并支持 100 万 Token 上下文。

    来源：阿里云百炼模型文档、ModelScope Qwen3.8 合集

    超长上下文、稀疏 MoE 和开源分发继续是国产模型争夺开发者生态的核心路径。对企业应用来说，百万级上下文降低了复杂文档、代码库和多轮任务的切片成本，但真实落地仍取决于推理成本、延迟和工具链稳定性。
